# IDEAS 设计规范

> 这份文档是**自包含**的。读完它，另一个工程师不需要看任何代码，
> 就能做出一个和 IDEAS Launcher 看起来是同一个家族的软件。
>
> 机器可读的版本在 [`tokens.json`](tokens.json)（由代码导出，不会和实现跑偏）。
> 参考截图在 [`reference/`](reference/)。

---

## 1. 这套设计的性格

**安静、方正、克制。** 界面不装饰自己：没有渐变、没有阴影、没有圆角的大卡片、
没有花哨的动画。信息靠**位置和留白**分层，不靠边框和色块。

一句话：**它应该看起来像 Windows 自己的一部分，而不是一个装在 Windows 里的东西。**

四条原则：

1. **形状服从系统。** 窗口的轮廓由操作系统决定，我们不去和它争。
2. **颜色是角色，不是颜色。** 界面说"第二级文字"，不说"灰色"。
3. **留白是主要的分隔手段。** 线和色块是补充，不是主力。
4. **能少一个像素就少一个像素。** 没有装饰性元素。

---

## 2. 形状：为什么窗口是方的

**窗口和卡片是直角（0 圆角）。** 圆角只用在**小组件**上：
徽章（6）、控件（8）、列表行（10）。

这不是审美偏好，是**被 Windows 教育过**的：

> Windows 11 会给**每一个**顶层窗口按自己的半径（8 点）裁剪客户区。
> 如果程序自己再画一个半径 14 的圆角卡片，两条弧线对不上，
> 夹在中间的那条缝就会露出窗口底下的东西 —— 在深色桌面上是四个黑角。

配套的三条规矩：

| 规矩 | 怎么做 |
|---|---|
| 不要自己画窗口的圆角 | 想要圆角，就让系统去切；想要方的，就告诉系统别切 |
| 不要在窗口边缘画阴影 | 窗口就是窗口的尺寸，阴影没有落脚的地方 |
| 不要在窗口边缘留透明边距 | 留了就会有一条缝，而且那一圈会**吃掉点击** |

**给别的工程师的版本**：窗口要圆角，就用系统给的；不要自己画。

## 3. 层级：颜色是角色

界面里出现的每一种颜色都属于一个**角色**。主题负责给角色填色，
程序只说"我要第二级文字"。

| 角色 | 含义 | 用在哪 |
|---|---|---|
| `surface` | 窗口的背景 | 整个窗口 |
| `surface_alt` | 浮在背景上的面 | 设置页的导航列 |
| `border` | 一条发丝线 | 分隔线、描边 |
| `text` | 重要的文字 | 标题、正文 |
| `text_dim` | 陪衬的文字 | 设置项的名称 |
| `text_faint` | 几乎看不见的文字 | 提示、路径、页脚 |
| `glyph` | 图标本身 | 放大镜 |
| `accent` | 强调色 | 选中态、匹配上的文字、徽章字母 |

**强调色不是随便挑的**：它取自主题主色的色相，在 ±55° 内按标题哈希浮动，
饱和度锁在 `[0.45, 0.85]`，明度按主题明暗取 `0.88` / `0.50`。
所以列表里的徽章互相能分辨，又不会跳出主题的调子。

**内置 16 个主题**（深色 11 个 + 浅色 5 个）的完整色值在 `tokens.json` 里。
最常用的是：

| 主题 | 适合 |
|---|---|
| `Midnight` | 默认深色 |
| `Win11` | 默认浅色（跟随系统） |
| `Darker` | 极简深色 |
| `Gray` | 中性深色 |
| `SlimLight` | 极简浅色，8 点圆角 |
| `Dracula` / `Nord Darker` / `Ubuntu` / `Pink` / `Cyan Dark` / `Sublime` / `Discord Dark` / `League` | 各种性格 |

## 4. 版式：两套刻度

### 4.1 间距

只用这六档，**不许自己发明数字**：

| Token | 磅 | 用在哪 |
|---|---|---|
| `XS` | 4 | 标签和它描述的东西之间 |
| `SM` | 8 | 同一组元素之间 |
| `MD` | 12 | 面板的内边距 |
| `LG` | 14 | 卡片的内边距 |
| `XL` | 20 | 两组之间 |
| `XXL` | 28 | 一页开始之前 |

### 4.2 字号

| Token | 磅 | 用在哪 |
|---|---|---|
| `CAPTION` | 11 | 提示、路径、脚注 |
| `LABEL` | 12 | 设置项的名称 |
| `BODY` | 13 | 正文、结果的标题 |
| `SUBTITLE` | 14 | 结果的第二行 |
| `TITLE` | 16 | 一个面板的标题 |
| `DISPLAY` | 18 | 程序名 |

### 4.3 字体栈

```
拉丁字母  →  Segoe UI
汉字      →  微软雅黑 UI（msyh.ttc 的第 2 个面）
```

**一个字体链，一个回退顺序**：拉丁走 Segoe UI，汉字走雅黑。
不要给汉字单独换一个字体——中英混排时两边会互相不搭。

用雅黑的 **UI 面**而不是普通面：它的小字号行距是收紧过的，正文才不散。

## 5. 组件规格

### 5.1 搜索框

```
高 50 · 左内边距 16 · 放大镜 22px · 放大镜到文字 10px · 字号 18
```

- 放大镜用 `surface_alt` 色，**不是** `text`。
- 提示文字（"搜索程序、文件、网页…"）用 `text_faint`。
- 输入的文字用 `text`。
- 搜索框下面一条 1px 的 `border` 分隔线 —— 把它和结果列表分开。

### 5.2 结果行

```
高 58 · 行与行之间空 4 · 图标 32 · 图标左边空 10 · 图标到文字 14
```

```
┌────────────────────────────────────────────────┐
│  [图标]  标题（16 磅）                          │
│           第二行（13 磅，text_dim）              │
└────────────────────────────────────────────────┘
```

- 标题里的**匹配部分**用 `accent` 色，其余用 `text`。
- 第二行是路径或说明，用 `text_dim`。
- 两行之间的距离由**字体的真实行高**算出来，不是写死的偏移量 ——
  这样用户改字号时两行永远不会叠在一起。

### 5.3 徽章

没有图标的结果（网页搜索、书签、系统命令、系统设置、文件）画一个徽章：

```
28×28 · 圆角 6 · 字母 14 磅
底色 = accent 色，20% 不透明度
字母 = accent 色本身
```

字母取标题的**第一个字母**（大写）；中文标题取第一个汉字。
**跳过前导的标点和数字** —— 标题是"（48条消息）一篇文章…"时，
徽章上不能是一个孤零零的括号。

### 5.4 选中态

```
底色 = accent 色，15% 不透明度
左边一条 2.5×18 的竖条，accent 色，圆角 2
```

竖条在行内垂直居中。**不要**再加一圈描边。

### 5.5 页脚

```
高 30 · 字号 12 · text_faint
上面一条 1px 的 border 分隔线
左边：快捷键提示      右边：时钟
```

### 5.6 设置页

```
左：导航列 168 宽，surface_alt 底
    顶部是"设置"，16 磅，加粗
    每项 13 磅，行高 30，选中项 accent_soft 底
    底部是"关闭 (Esc)"
右：内容区
    面板标题 16 磅，加粗，下面一条分隔线
    设置项名称 12 磅，text_dim
    下面的说明 11 磅，text_faint
    控件之间空 8，一组和下一组之间空 14
```

### 5.7 托盘菜单

系统原生菜单，右键托盘图标弹出：

```
显示搜索窗口    Alt + Space
设置…
──────────────
退出
```

**菜单里显示的快捷键必须是当前真正生效的那个** —— 如果配置的组合被别的程序
占用了，程序会退到备选组合上，菜单里要显示退到的那个。

## 6. 交互

| 动作 | 结果 |
|---|---|
| 全局热键 | 显示搜索窗口（带淡入和轻微上移，`motion::FADE` 0.14 秒，`motion::SLIDE` 10 点） |
| 托盘左键 | 同上 |
| 托盘右键 | 弹出菜单 |
| 输入 | 立刻重新查询，不等防抖 |
| ↑ / ↓ | 上下选，跨过列表顶部时循环 |
| Enter | 打开 |
| Esc | 关闭 |
| Ctrl + C | 复制选中项 |
| Tab | 用选中项补全搜索词 |
| 窗口失去焦点 | 自动隐藏 |

**丢焦点就隐藏**是这类启动器的关键手感：它必须在你点回别处之前就消失。

## 7. 禁忌

这一节是这个项目里最值钱的部分 —— 每一条都是**真的踩过**的坑。

| 别做 | 后果 |
|---|---|
| **别自己画窗口的圆角** | 系统已经切了一个，两条弧夹出的缝会露底，深色桌面上就是四个黑角 |
| **别用 `DWMWCP_DONOTROUND` 去改透明窗口** | 属性写得进去，形状不变 —— 对**不透明**窗口才有效 |
| **别给窗口留透明边距** | 边距会**吃掉点击**，落在那儿的点击不会传给下面的程序 |
| **别让引擎用默认的清屏色** | 默认是近黑七成不透明；没画到的地方会留一圈脏边 |
| **别在窗口里铺半透明的"玻璃"** | 系统会自动给带标题栏样式的窗口铺一层 Acrylic，界面看起来像两层 |
| **别把窗口边框交给 DWM 画** | 它沿**矩形**画，会把圆角填成方的 |
| **别用固定偏移量排两行文字** | 标题和副标题会叠在一起；要用字体的真实行高 |
| **别在滚动列表底部硬切** | 最后一行被切一半像画错了，让它淡出 |
| **别相信"读回来和写进去一样"的验证** | 用自己假设的格式去构造测试输入，测一百遍也是绿的 |

## 8. 给下一个程序的检查清单

- [ ] 所有间距都来自 `space` 刻度，所有字号都来自 `typography` 刻度
- [ ] 颜色只通过角色取用
- [ ] 窗口形状交给系统
- [ ] 中文走微软雅黑 UI，拉丁走 Segoe UI
- [ ] 结果行有两行时，行距由字体行高算出来
- [ ] 没有图标的东西有徽章，徽章不显示标点
- [ ] 选中态是淡底 + 左侧竖条，不加描边
- [ ] 失焦自动隐藏
- [ ] 深色主题下每一个角色都读得清
